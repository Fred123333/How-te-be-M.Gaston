# Moulin de France Douala - Premium Restaurant Website

## 🎨 Project Overview

A stunning premium restaurant and bakery website for **Moulin de France Douala**, created to Awwwards quality standards. The site showcases an elegant, warm, and immersive user experience that reflects the luxury and craftsmanship of the establishment.

## 📋 Key Features

### 1. **Navigation & Branding**
- Sticky navbar with scroll animations
- Mobile-responsive hamburger menu
- Premium typography using Playfair Display, Cormorant Garamond, and Poppins fonts
- WhatsApp integration for easy contact

### 2. **Hero Section**
- Full-screen immersive background image
- Animated title and CTA buttons
- Scroll indicator animation
- Dark overlay for text readability

### 3. **About Section (Notre Histoire)**
- Brand story with immersive imagery
- Four core values displayed as elegant cards:
  - Passion 🔥
  - Tradition 🏛️
  - Quality ⭐
  - Authenticity 🌍

### 4. **Specialties Section**
- Four featured product categories with stunning imagery:
  - Pâtisseries (Pastries)
  - Pizzas Artisanales (Artisanal Pizzas)
  - Burgers Gourmets (Gourmet Burgers)
  - Glaces Artisanales (Artisanal Ice Cream)
- Hover animations and pricing information

### 5. **Interactive Menu**
- 5 category filters:
  - Petit Déjeuner (Breakfast)
  - Déjeuner (Lunch)
  - Dîner (Dinner)
  - Boissons (Beverages)
  - Desserts & Pâtisseries
- 15 menu items with descriptions and prices
- Smooth category switching with animations

### 6. **Image Gallery**
- Masonry layout with responsive grid
- 6 premium food and ambiance photographs
- Hover effects and lightbox viewer
- Full-screen image preview

### 7. **Why Choose Us**
- 6 reason cards with icons
- Hover animations and visual emphasis
- Clear value propositions:
  - Fresh products
  - Artisanal cuisine
  - Fast service
  - Warm environment
  - Premium quality
  - Authentic flavors

### 8. **Testimonials**
- Auto-rotating carousel (5-second interval)
- Star ratings and customer avatars
- Manual navigation with dot indicators
- Smooth fade animations

### 9. **Events & Occasions**
- 4 event categories:
  - Anniversaires (Birthdays)
  - Mariages (Weddings)
  - Buffets
  - Réceptions (Events)
- Each with description and "Learn more" CTA

### 10. **Location & Contact**
- Embedded Google Map
- Address, phone, and business hours
- WhatsApp contact button
- Complete contact information

### 11. **Footer**
- Comprehensive site navigation
- Contact details
- Business hours
- Social media links
- Copyright information

## 🎨 Design System

### Color Palette
- **Primary**: #41141B (Burgundy) - Premium, sophisticated
- **Accent**: #EEA637 (Gold) - Luxury, warmth
- **Background**: #FFFFFF (White) - Clean, airy
- **Text**: #2D2D2D (Dark Gray) - Readable
- **Muted**: #F8F8F8 (Off-white) - Subtle contrast

### Typography
- **Headings**: Playfair Display (elegant, serif)
- **Display**: Cormorant Garamond (refined, serif)
- **Body**: Poppins (modern, readable)

### Spacing & Layout
- Mobile-first responsive design
- Generous whitespace for premium feel
- Grid-based layouts (2, 3, 4 columns on desktop)
- Consistent padding (16-32px sections)

## 🚀 Technologies Used

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Carousel**: Embla Carousel
- **Icons**: Lucide React
- **Fonts**: Google Fonts (Playfair Display, Cormorant Garamond, Poppins)
- **Images**: Optimized PNG images

## 📱 Responsive Design

- ✅ Mobile (375px)
- ✅ Tablet (768px+)
- ✅ Desktop (1024px+)
- ✅ Large Desktop (1280px+)

All sections adapt smoothly with:
- Flexible grids (1 → 2 → 3 → 4 columns)
- Touch-friendly spacing on mobile
- Readable font sizes across devices
- Optimized image sizes

## 🎬 Getting Started

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build

# Start production server
pnpm start
```
