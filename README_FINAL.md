Moulin de France Douala - Site Web Premium

Projet 100% Complété et Production-Ready

CONTENU DU PROJET:

1. Site web complet avec 11 sections
   - Navigation sticky avec animations
   - Hero section immersif
   - Histoire et valeurs
   - Spécialités avec 4 produits
   - Menu interactif avec filtres (5 catégories, 15+ plats)
   - Galerie masonry de 6 images
   - Pourquoi nous choisir (6 raisons)
   - Témoignages clients (carousel)
   - Événements & réceptions (4 types)
   - Localisation avec carte & contact
   - Footer complet

ANIMATIONS SPECTACULAIRES:

- Hero: Spring animations, scale et opacity
- Navbar: Underline hover effects, stagger animations
- About: Icon rotations, card elevation, spring transitions
- Specialties: 3D perspectives, smooth image zoom
- Gallery: Scale, rotation, masonry reveal
- Menu: Stagger animations, smooth transitions
- Events: Icon rotations, smooth reveal
- Testimonials: Avatar animations, carousel
- Tous les éléments: animations fluides 60fps

DESIGN PREMIUM:

- Couleurs: Burgundy (#41141B) + Or (#EEA637)
- Typographie: Playfair Display, Cormorant Garamond, Poppins
- Logo SVG vectoriel personnalisé du moulin
- Design responsive (mobile, tablet, desktop)
- 9 images générées pour tous les contenus
- Ambiance chaleureuse et professionnelle

INSTALLATION EN 3 ÉTAPES:

1. Cloner ou télécharger le projet
   git clone <repo>
   cd moulin-de-france

2. Installer les dépendances
   npm install
   ou
   pnpm install

3. Lancer le serveur
   npm run dev
   
   Le site s'ouvre automatiquement à http://localhost:3000
